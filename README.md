# Smart Campus Shield Project

This directory is intended to hold the source files for the **Smart Campus Shield** web application that is deployed at `https://smart-campus-shield-hioy9z0dj-vasu-5d29.vercel.app`.

## Suggested Structure

```
smart-campus-shield/
├─ public/            # Static assets (HTML, CSS, images, etc.)
├─ src/               # Source code (React, Next.js, etc.)
├─ package.json       # Project manifest
├─ README.md          # This file
└─ .gitignore         # Git ignore rules
```

## How to Use
1. Clone this folder to your local machine.
2. Add your project files (e.g., `index.html`, `app.js`, etc.) under the appropriate directories.
3. Initialize a Git repository and push it to GitHub.
4. Connect the repo to Vercel for deployment.

You can set this folder as your active workspace in Antigravity:
```
agy workspace set C:\Users\ramas\.gemini\antigravity\scratch\smart-campus-shield
```

Feel free to modify the structure to match your framework (Next.js, Vue, plain HTML, etc.).
